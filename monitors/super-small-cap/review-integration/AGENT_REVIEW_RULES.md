# Independent super-small-cap review dispatch v1

This producer connects the existing third collector to the installed local Crypto Lab
model and existing Telegram bot/chat. It does not change the interactive agent's
command allowlist, scanner thresholds, other triggers or weights. No expiry or trading.

The agent selects a setup hypothesis and evidence references in a constrained JSON
response. The worker constructs every factual sentence from the immutable evidence
packet; model-written facts and commands are never accepted. This reduces invented
facts but does not prove judgment quality. Do not describe selection as trained skill
or calibrated predictive confidence.

Review actual exact-pair observations over 60–180 seconds. Missing or gapped history
stays EARLY_WATCH. Core screening UNKNOWN stays EARLY_WATCH; background UNKNOWN is
disclosed. Supported Pump AMM pools use the existing free RPC decoder in an isolated
store; bonding curves and unsupported pools remain unknown. Never copy a PASS from a
different pool or replace an explicit rejection with missing evidence.

FIRE_REVIEWED requires a separate structured agent decision and the validator's full
evidence checks. The producer supplies both an earlier held-gain and failure comparator
from this collector's own completed prospective one-hour observations, with uninterrupted
sampling and liquidity within a factor of two. Protected prediction-ledger mints are
excluded by mint-only inventory reads. No protected outcomes are read. The original
larger-cap historical study remains explicitly non-comparable. When a comparable pair
is unavailable, retain at most PROMISING_SETUP. This is evidence policy, not a fitted
profitability filter. No minimum return, higher-low rule or headline volume threshold
automatically promotes or rejects a current candidate.

The factual participation section distinguishes rolling five-minute counts from
independent buyers, fresh-window flow and executable exit quotes. The thesis remains
a speculative price-action hypothesis. Invalidation cites the observed window low,
verified control rejection or liquidity loss; it is not an optimized stop loss.

Persist the original discovery unchanged, each assessment's evidence hash and actual
decision price/time, and a separate delivery ledger. Re-read current screening and cap
after inference. Changed or stale evidence blocks sending. Only FIRE_REVIEWED is sent,
with prefix 🔥 SUPER SMALL CAP — EXPERIMENTAL. A committed delivery attempt, including
an ambiguous timeout, cannot automatically resend. Stop markers pause capture/review
or review alone; never stop another trigger. There is no synthetic candidate message
in production validation.

Partial discovery, queue bounds, screening/inference errors and missing comparable
cases must remain visible in aggregate status. This is an experimental reviewed
research stream, not a validated runner detector. Prospective outcome analysis and
model selection-quality evaluation remain separate research tasks.
